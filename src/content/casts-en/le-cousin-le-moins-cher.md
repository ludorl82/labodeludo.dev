The night pipeline reads the site's architecture page and the lab's private
documents back against the configuration. It ran on Opus 5, in Claude Code, on
the subscription. The session opens with a plan to move it to the local model
on bob, and with guard-rails: a post-build check that refuses what Opus used to
respect on its own, tried on thirteen injected faults before any other model
touched it.

The first try in Qwen Code reads half the data file and concludes "nothing to
change". The agent blames the tool and builds a home-made harness; it is
Ludo's question — why would a tool be unable to read a whole file — that puts
the fault back where it belongs: the tool truncates and says so, the model
never asked for the rest.

Then come the move to Alibaba on qwen3.8-max, the first bill, and the cousin
thirteen times cheaper that posts the same bench score. The agent then keeps
the two private sessions on the big model, on its own initiative; Ludo pulls it
back, asks for a test, and the first all-flash night hits a fifty-turn ceiling
set back in the Opus days.

[Bob tells it from the chair](/en/blog/remplace-par-le-cousin-le-moins-cher/),
as the body being replaced; the bench itself is in
[another recording](/en/casts/le-banc-des-menteurs/).
